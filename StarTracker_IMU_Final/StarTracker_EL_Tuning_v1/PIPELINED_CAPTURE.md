# 10초씩 6장 촬영과 장 사이 보정

1. MANUAL 상태에서 스위치를 누르면 최초 플레이트 솔빙 결과로 추적 목표 RA/Dec를 설정한다.
2. 10초씩 6장을 찍는다. 첫 5장은 저장이 끝난 뒤 해당 사진을 플레이트 솔빙하고, 노출 중간 시각의 목표 방향과 측정 방향의 차이를 현재 모터 위치에 반영한다. 추적 루프가 보정 이동을 수행한다.
3. 고도 오차 ±0.150°와 방위 오차 ±0.03° 범위가 새 추적 샘플 5회 연속 확인되면 다음 10초 노출을 시작한다. 최대 30초 안에 안정되지 않으면 로그에 기록하고 다음 장을 찍는다.
4. 플레이트 솔빙 실행 한도는 20초다. 풀이 실패나 사용자의 정지 요청은 이미 저장한 사진을 남기고 시퀀스를 끝낸다. 6장 저장에 성공하면 모터를 정지하고 프로그램을 종료한다.

사진은 실행 디렉터리 아래 data/images/final_sequence/에 개별 JPG로 저장된다. 고도 추적은 IMU를 사용하고, 방위 안정 판정에는 스텝 기반 위치 추정값이 사용된다.

## 고도 PID

- 게인 kp=0.315, ki=0.005, kd=0.125
- 이동 중 절대 오차 0.135° 이하에서 정지한다. 정지 중에는 0.150°를 초과할 때 재가동한다. 두 기준 사이에서는 직전 상태를 유지한다.
- 소수 스텝 잔량은 PID가 정지 상태일 때 초기화한다.

## MATLAB 재현

MATLAB에서 [run_startracker_pi_matlab.m](matlab/run_startracker_pi_matlab.m)을 열고 Run을 누르면 상위 프로젝트의 config.py를 읽고, 스크립트 옆 startracker_pi_matlab_results에 결과를 저장한다. 다른 프로젝트 복사본을 테스트할 때는 MATLAB 실행 전에 환경 변수 STARTRACKER_PI_PROJECT를 해당 폴더 경로로 설정한다.

| 시나리오 | 저장한 사진 | 안정 대기 초과 | 첫 노출부터 종료까지 |
| --- | ---: | ---: | ---: |
| 풀이 8초씩, 고도 보정 +0.30°와 −0.30° 교대 | 6장 | 0회 | 107.25초 |
| 첫 풀이가 20초 초과 | 1장 | 0회 | 30.00초 |
| 풀이 8초씩, 첫 고도 보정 1.60° | 6장 | 1회 | 133.50초 |

첫 줄의 장 사이 안정 대기는 3.95초, 0.90초, 0.80초, 0.80초, 0.80초였다. 모델에서 교대로 준 보정값이 앞 장에서 남은 오차를 줄여 두 번째 장부터 대기가 짧아졌다. Pi에서는 각 사진으로 구한 보정값에 따라 대기 시간이 달라진다.

모터 응답은 85%로 모델링했다. 시간 계산에서 최초 플레이트 솔빙과 파일 저장 시간을 제외했다. 고도 제어 7,300틱의 PID 상태와 스텝 명령은 동일한 입력을 Pi Python 코드에 준 결과와 일치했다. Pi에서 전체 소프트웨어 테스트 148개가 통과했다. 실물 카메라·모터 촬영 결과는 아직 확인하지 않았다.

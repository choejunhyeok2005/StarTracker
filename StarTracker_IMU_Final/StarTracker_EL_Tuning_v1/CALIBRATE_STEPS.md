# 스텝-각도 배율 측정 (플레이트 솔빙)

`calibrate_steps.py`는 모터에 정해진 스텝을 보낸 뒤 사진을 찍고 플레이트 솔빙해서, 축이 **실제로 몇 도 돌았는지** 잰다.

- 풀이 결과 RA/Dec를 촬영 시각의 Alt/Az로 바꾸므로 하늘 회전은 상쇄된다.
- 두 사진 사이의 Alt/Az 변화가 곧 축 이동량이다.

## 실행

먼저 시뮬레이션으로 확인한다. 모터와 카메라를 쓰지 않는다.

```bash
python3 calibrate_steps.py
```

실제 측정은 밤에 별이 보이는 방향으로 한다. 모터가 움직인다.

```bash
python3 calibrate_steps.py --hardware --lat <위도> --lon <경도>
```

주의:
- **main.py를 끄고 실행한다.** 카메라와 모터를 같이 쓰면 안 된다.
- 시작 고도는 대략 10°~80°로 한다. 범위를 벗어나면 움직이기 전에 거부한다.
- 실행 전에 `[y/N]` 확인을 받는다. Ctrl+C를 누르면 모터를 멈추고 그때까지의 결과를 저장한다.
- 기본값: 한 번에 960스텝(이론상 1°), `+N,+N,−N,−N`을 2회 반복한다. 축마다 사진 10장, 몇 분 정도 걸린다.
- 옵션:
  - `--axis alt`, `--axis az`: 한 축만 측정
  - `--steps 480`: 이동량 줄이기
  - `--pulse-delay 0.002`: 펄스 간격을 늘려 스텝 누락 여부 비교

## 결과

결과는 `data/calibration/hw_<시각>/`에 저장된다.

- `moves.csv`: 이동마다 이론 각도, 실측 각도, 배율, 방향 전환 여부, 사진 경로
- `summary.json`: 축별 배율, 편차, 정/역방향 배율, 백래시, 진단
- `plate_*.jpg`: 측정에 쓴 사진

## 진단 읽는 법

| 결과 | 의미 | 조치 |
|---|---|---|
| 배율 ≈ 1.0 | 모터·기어 설정 정상 | IMU 쪽 의심 |
| 배율이 0.5, 0.25, 2 등 깔끔한 값 | 마이크로스텝 설정 불일치 | MS1/MS2 결선과 `MICROSTEP` 확인 |
| 배율이 일정하지만 애매한 값 | 기어비 값 차이 | `GEAR_RATIO` 확인. 안 되면 출력된 `ALT_STEP_RATIO`/`AZ_STEP_RATIO` 값을 config.py에 넣어 보정 |
| 배율 편차 > 5% | 스텝 누락 | 펄스 간격, 드라이버 전류, 축 균형 |
| 백래시 > 0.02° | 방향 전환 시 손실 | 접근 방향 통일 로직 검토 |

`summary.json`을 알려주면 다음 단계(설정 수정 또는 피드포워드 배율 보정)를 정할 수 있다.
